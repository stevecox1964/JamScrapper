## Decisions locked in this session

- **New song = fresh live player.** Don't go back to reusing it with `loadVideoById()`; that
  is what left long-open pages stuck.
- **Hide, don't delete.** UI trims go behind a `const` flag in `App.jsx`.
- **Header is Live / Local.** Live = follow Pandora. Local = play from the app's own library.
- **No video in Live mode → automatic band-image slideshow**, not a still image, not MTV Mode.
- **Self-reliance:** outside music services (Pandora, any other) are only for random song
  picks and cataloging — never for video, playback position, play/pause, or listen time.
  So the idea of reading Pandora's playback position through the Chrome extension was dropped.
- **Videos still come from YouTube via yt-dlp**, once per song; after that the file is ours.
  The user knows this breaks YouTube's terms.
